# Anvil of Legends — releases

Release downloads for **Anvil of Legends**, a Foundry VTT module for D&D 5e map prep (token rings, a token art picker for your own token library, and more to come). The source lives in a private repository; this one only hosts the packaged releases.

Requires Foundry VTT 12 and the dnd5e system.

## Install
In Foundry's Setup screen: **Add-on Modules → Install Module**, paste this into **Manifest URL**, and click **Install**:

```
https://github.com/realEBongo/AnvilOfLegends-releases/releases/latest/download/module.json
```

Then enable it in your world under **Game Settings → Manage Modules**.

## Update
**Add-on Modules → Check for Updates** in Setup. After updating, restart the world so Foundry rereads the module.

Release notes are on the [Releases](https://github.com/realEBongo/AnvilOfLegends-releases/releases) page.
